# Seedance 2.5 Prompting v2

스토리·이미지를 읽고 장면, 카메라, 연기, 음향을 씨댄스 2.5용 전체 프롬프트로 작성하는 배포용 Codex 스킬 묶음입니다. **v2 / 2.1.0은 이 스킬 묶음의 버전**이며, 대상 영상 모델은 Seedance 2.5입니다.

기존 `seedance-2-5-prompting` 저장소와 분리한 독립 v2 공개 저장소입니다. 로그인이나 초대 없이 열람하고 내려받을 수 있습니다.

## 포함된 스킬

| 폴더 | 역할 |
| --- | --- |
| [seedance-2-5-prompting](skills/seedance-2-5-prompting/SKILL.md) | 입력 해석, 레퍼런스 역할, 타임라인, 카메라·음향, 전체 프롬프트 작성·수정 |
| [seedance-25-cinematic](skills/seedance-25-cinematic/SKILL.md) | 영화 같은 사건·연기·조명·대사·원테이크 연출 |
| [eyecandy-visual-development](skills/eyecandy-visual-development/SKILL.md) | 장면의 감정과 공간에 맞는 구도·무빙·전환 선택 |
| [video-effects](skills/video-effects/SKILL.md) | 영화·광고·뮤직비디오용 14가지 효과의 원리, 장면별 추천과 범용 프롬프트 |

GODSTOUCH 액션 카메라, NO-BGM, 스토리·이미지 해석, 2.5 작성법 5팁은 기본 스킬의 참고자료에 포함됩니다. 아이캔디의 장면 연결용 모티프 참고자료도 함께 들어 있어 특정 개인 PC의 HERA 설치 경로에 의존하지 않습니다.

## v2에서 할 수 있는 일

- 스토리만, 이미지만, 둘 다 받아 어울리는 장면을 구성합니다.
- 장면의 감정·서사·제품 정보·음악 흐름에 맞는 VFX를 추천하고 효과의 시작·변화·끝을 프롬프트로 풀어 씁니다. 눈동자가 보인다는 이유만으로 눈 통과 전환을 강제하지 않으며, 효과 없이 촬영하는 선택도 유지합니다.
- 시간 정지, 공간 분리, 분신, 용해 등 효과를 힉스필드 계정이나 플러그인 없이 다른 영상 도구용으로도 작성합니다. 씨댄스에서는 기존 길이·참조 태그·음향·컷 정책을 유지합니다.
- 장면의 핵심과 사용자 지정 조건을 먼저 정하고 필요한 연출 지시만 선택합니다. 공통 카메라 조건은 한 번 쓰고, 첫 실패부터 해당 제약만 보강합니다.
- 담백한 장면은 필요한 반응과 구도에 집중하고, 복잡한 장면의 필수 동선·접촉·명시한 복합 연출은 보존합니다.
- 뮤직비디오도 같은 기본 스킬에서 요청한 길이로 씁니다. 10초·15초·20초라는 이유로 별도 스킬, 고정 길이 분할, Fast 프로필을 선택하지 않습니다.
- 얼굴·의상·공간·행동·카메라·음향 참조의 역할과 우선순위를 분리합니다.
- 장면에 맞는 렌즈, 고정 또는 주 이동, 경로·속도·초점·끝 구도를 씁니다.
- 영화 같은 반응을 신체 부위·행동·횟수/속도로 구체화하고 접촉을 인과 순서로 연결합니다.
- 요청한 원샷·컷 정책·길이를 유지하며 추격·충격·등장 장면의 카메라를 보강합니다.
- NO-BGM, 완전 무음, 현장음, 무반주 보컬, 첨부 음원 전용을 구분합니다.
- 첫 실패부터 결과나 설명을 보고 수정한 전체 프롬프트를 반환합니다. 고정된 실패 횟수나 다른 테이크의 자동 채택을 적용하지 않습니다.
- 정확한 문자 수와 충돌을 점검합니다. 기본 2.5 작성 상한은 5,000자이며 초과 시 간체 중국어로 압축합니다. 사용자가 언어를 고정하면 그 언어를 유지합니다.

이 수치와 작성법은 스킬의 제작 규칙입니다. 모델의 공식 한도나 생성 성공을 보장하지 않습니다. 실제 생성 모드·오디오 전이·출력 설정은 사용하는 UI에서 확인합니다. 영상 생성은 별도로 요청된 제작 작업에서만 실행합니다.

## 설치

1. GitHub에서 ZIP으로 내려받거나 Git으로 복제합니다:

   ```bash
   git clone https://github.com/babicat4242-svg/seedance-2-5-prompting-v2.git
   ```

2. `skills` 안의 네 폴더를 사용 중인 Codex의 개인 스킬 디렉터리에 나란히 복사합니다. 이 묶음에서 사용하는 기본 위치는 Windows의 `%USERPROFILE%/.codex/skills`, macOS/Linux의 `~/.codex/skills`입니다. 이미 같은 이름의 스킬이 있으면 해당 폴더를 백업한 뒤 교체합니다.

설치 후 디렉터리 구조:

```text
.codex/skills/
  seedance-2-5-prompting/
    SKILL.md
    references/
    scripts/
  seedance-25-cinematic/
    SKILL.md
    references/
  eyecandy-visual-development/
    SKILL.md
    references/
    techniques/
  video-effects/
    SKILL.md
    references/
```

저장소 루트 자체를 스킬 하나로 설치하지 말고, 위 네 폴더를 함께 설치합니다. 내부 스킬 이름은 연결 호환성을 위해 유지했습니다. 기존 공개 저장소의 원격 주소를 이 저장소로 변경할 필요는 없습니다.

## 사용 예시

```text
이 이미지와 스토리로 씨댄스 2.5용 20초 원샷 프롬프트를 써줘.
영화 같은 분위기로, 인물 반응이 읽히는 카메라를 골라줘.
대사는 없고 발소리만 허용하는 NO-BGM이야.
```

```text
첫 결과에서 원치 않는 줌과 음악이 들어갔어.
인물과 사건은 유지하고 카메라 고정과 현장음만 남도록 수정해줘.
현재 지시만 담은 전체 프롬프트를 다시 작성해줘.
```

## VFX 사용 예시

효과 이름을 모르는 상태에서도 장면을 설명하면 어울리는 효과를 제안합니다. 같은 효과를 영화의 기억·감정, 광고의 제품 공개, 뮤직비디오의 퍼포먼스·반복에 맞춰 다르게 활용할 수 있습니다.

```text
눈동자 클로즈업에서 인물의 기억 속 방으로 들어가는 영화 장면이야.
씨댄스 2.5용 15초 원샷으로, 어울리는 VFX를 골라 전체 프롬프트로 써줘.
```

```text
$video-effects 향수병만 공중에 정지하는 광고 장면을 써줘.
인물 없이, 특정 영상 도구에 의존하지 않는 프롬프트만 작성해 줘.
```

```text
씨댄스 2.5 뮤직비디오에 공간이 레이어로 벌어졌다 돌아오는 효과를 넣어줘.
기존 인물과 음원 태그, 원본 음원 전용 조건, 요청한 길이를 유지해 줘.
```
