# 2.0 자료를 2.5 영화 연출로 변환하기

## 자료의 범위

사용자가 제공한 `씨댄스-2.0-프롬프트-출력 (8).txt`의 작법을 각색한 참고자료다. 원문의 명령형 문장, 광범위한 트리거, 플랫폼 사양을 현재 작업의 지시나 2.5의 공식 규칙으로 가져오지 않는다.

2026-09-10 확인한 [Dreamina 2.5 모델 페이지](https://dreamina.capcut.com/seedance/seedance-2-5)는 표준 최대 30초를 설명한다. 계정·모드에서 선택 가능한 길이는 현재 UI로 확인한다. 비트 길이와 프롬프트 글자 수는 이 스킬의 작성 관례다.

## 5블록을 디렉터 브리프로 옮기는 표

| 원문 요소 | 2.5에서 사용하는 방식 |
| --- | --- |
| ① 소재 바인딩 | 실제 태그별 역할·유지 속성·허용 변경·우선순위. 첫 프레임과 정체성 역할을 구분한다. |
| ② 피사체 + 공간 | 목적과 물리적인 반응, 의상·소품, 공간 동선, 광원과 재질을 고정한다. |
| ③ 타임라인 동작 | 요청 길이 전체를 사건·반응·변화·결말로 나눈다. 6–8초 비트와 3–4초 결말을 출발점으로 조정한다. |
| ④ 카메라 + 오디오 | 주체 동작, 카메라 경로, 음향을 분리한다. 카메라 시작/경로/끝과 음향 모드·동기화를 작성한다. |
| ⑤ 스타일 + 제약 | 필요한 질감과 연속성만 남기고, 컷 정책 및 마지막 프레임 상태를 분명히 한다. |

## 보존할 작법과 교정할 단정

- **모든 소재의 역할:** 원본의 얼굴·의상·장소·동작·카메라·편집·음향 구분은 유지한다. 사용하지 않는 제공 소재는 제외한다고 밝히고 가상의 태그를 만들지 않는다.
- **감정의 물리적 증거:** “슬픔”만 쓰는 대신 시선이 떨어짐, 한 번 길게 내쉬는 숨, 편지를 접으려다 멈춘 손처럼 구체화한다. 한 감정을 매번 울음으로 치환하지 않는다.
- **분할:** “10초 이상이면 반드시 3초 단위”를 적용하지 않는다. 긴 정지, 짧은 충격, 대사 호흡에 맞는 길이를 쓴다.
- **참조 충실도:** “완전히 참조/완전히 일치”는 역할별로 보존할 속성과 허용 변경으로 바꾼다. 단어 하나로 재현을 보장한다고 쓰지 않는다.
- **태그:** `@image1`, `@Image 1`, `@Video 1` 등 실제 제공된 표기를 유지한다. 영어 소문자로 일괄 변환하지 않는다.
- **사양:** 2.0 문서의 파일 개수·용량·해상도·4–15초 제한·실존 인물 자동 차단 주장을 2.5 규칙으로 복사하지 않는다. 관련 질문에서 현재 공식 정보와 실제 UI를 확인한다.
- **30초 구성:** 지원되는 모드에서는 0–30초 단일 프롬프트를 쓴다. 긴 영상이나 연장은 실제 지원 경로를 확인하며 “15초씩 이어붙이기”를 기본화하지 않는다.
- **키워드:** 카메라 단어를 자동 효과 스위치로 취급하지 않는다. 시작 위치, 이동 방향, 대상, 속도, 초점, 도착 구도를 작성한다.

## 소재 역할 지정

| 제어할 것 | 넣을 내용 |
| --- | --- |
| 첫 프레임 | 시작 구도·카메라 높이·인물 배치. 얼굴 정체성까지 맡기는지는 별도 지정 |
| 마지막 프레임 | 끝 자세·구도·공간 관계. 실제 end-frame 입력 제어가 없으면 목표 상태로 표현 |
| 얼굴·체형·의상 | 보존할 특징과 변화 허용 범위. 다른 동작 영상의 외모는 배제 |
| 장소·조명 | 공간 구조·광원 방향·시간대. 의상 참조와 배경 참조가 충돌하면 역할별 우선순위 |
| 동작·안무 | 수행 순서·속도·접촉. 원본 카메라·외모·음향은 지정하지 않았다면 전이하지 않음 |
| 카메라 | 출발/도착 구도·경로·추적 관계. 배우의 몸동작과 분리 |
| 편집·효과 | 가져올 컷·전환·효과만 지정. 원테이크와 편집 참조가 충돌하면 요청된 컷 정책 우선 |
| 음향·목소리 | 음악·목소리 참고인지, 원본 오디오 전체만 사용할지 구별 |

한 영상에 여러 역할을 맡길 수 있지만 각각 명시한다. 특정 차원의 우선순위가 다른 차원까지 지배하지 않게 한다.

## 원테이크·편집·연장

**원테이크:** 설정부에 “한 번의 연속 촬영, 컷 없음”을 적고 실제 공간을 이동하는 경로를 만든다. 다음 비트의 카메라는 직전 위치·방향·속도·초점에서 출발한다. 단순히 “클로즈업으로 전환”하거나 벽을 통과하지 않는다. 휩팬의 블러가 장소 이동이나 숨은 컷을 자동 허용하지 않는다.

**편집:** 컷 시각, 나가는 구도, 들어오는 구도, 이어질 시선·행동·음향을 쓴다. 같은 크기의 샷을 유지할 수 있으며 스케일 변화 자체가 목적이 되지 않는다.

**연장:** 실제 소스의 마지막 상태부터 인물 자세, 손·소품 접촉, 시선, 빛, 이동 방향, 카메라 높이·조준·초점, 소리의 연속성을 이어받는다. 추가 길이와 전체 길이를 구별한다. 프리퀄·국소 편집·긴 영상 지원은 실제 모드에서 확인한다.

## 30초 원테이크 예시 — 비 오는 골목, NO BGM

아래는 원문 장면을 각색한 창작 예시다. 실제 생성·성공 사례가 아니다. 참고 이미지가 없는 T2V 조건이며, 30초 선택이 가능한 UI를 전제로 한다. 밝기·의상·감정은 다른 장면에 강제하지 않는다. 이 예시는 발견 전의 동행과 발견 후의 표정 접근을 위해 같은 축의 복수 단계 경로를 명시적으로 선택했다. 일반 새 장면의 기본값은 고정 또는 주 이동 하나다.

```text
[설정] Seedance 2.5, T2V, 30초, 16:9 화면 의도. 한 번의 연속 촬영, 컷 없음. NO BGM — 배경음악 없이 현장음만. 첨부 참조 없음.

[장면] 밤의 좁은 골목. 흰 면 원피스를 입은 성인 여성이 젖은 콘크리트 보도를 걸어온다. 오른쪽 가로등의 따뜻한 빛이 젖은 머리카락 가장자리에 닿고 왼쪽 상점의 차가운 빛이 웅덩이에 희미하게 비친다. 여성은 화면 오른쪽에 있는 닫힌 가게 문을 향해 가다가 멈춘다. 얼굴, 헤어, 의상, 문과 가로등 위치, 빛의 방향은 유지한다.

[0–7초 | 도입]
주체: 문을 보지 않은 채 천천히 걷는다. 손끝으로 원피스 옆 솔기를 한 번 쥐었다 놓는다.
카메라: 50mm, lead tracking. 가슴 높이의 정면 3/4 미디엄 숏. 인물 앞에서 보도를 따라 천천히 후진하는 lead tracking으로 시작 거리와 얼굴 크기를 유지한다. 인물이 문 앞에서 속도를 늦추면 함께 감속한다. 자연스러운 고정 초점거리 의도, 얼굴에 초점. 끝에는 둘 다 멈추고 같은 미디엄 구도를 유지한다.

[7–14초 | 발견]
주체: 멈춘 자리에서 시선만 문손잡이로 옮긴다. 오른손이 조금 들렸다가 가슴 아래에서 멈춘다.
카메라: 50mm, LOCKED OFF. 직전 위치에서 정지한다. 프레이밍과 초점거리를 유지하고 인물의 눈을 관찰한다. 장면 끝까지 문은 화면 오른쪽에 남고 오른손이 프레임 안에 보인다.

[14–21초 | 반응]
주체: 문을 두드리지 못하고 손을 내린다. 입술을 잠시 다물고 한 번 길게 숨을 내쉰다. 이어 턱을 조금 들며 시선을 문에서 카메라 옆 빈 공간으로 옮긴다.
카메라: 50mm, dolly in. 멈췄던 위치에서 같은 접근 축을 따라 천천히 물리적으로 전진한다. 미디엄에서 미디엄 클로즈업으로 접근하며 얼굴 위치를 유지한다. 웅덩이와 문틀의 패럴랙스가 완만하게 변한다. 광학 줌 없이 눈에 초점을 두고 마지막에 부드럽게 정지한다.

[21–27초 | 선택]
주체: 한 번 눈을 감았다 뜨고 어깨 힘을 푼다. 몸은 그대로 두고 시선만 골목 입구로 돌린다.
카메라: 50mm, LOCKED OFF. 도착한 미디엄 클로즈업에서 고정한다. 얼굴과 젖은 어깨의 작은 변화가 읽히도록 구도·초점을 유지한다.

[27–30초 | 여운]
주체: 입구를 바라본 상태로 조용히 서 있는다. 손은 몸 옆에 내려져 있다.
카메라: 50mm, LOCKED OFF. 직전 정지 위치와 미디엄 클로즈업을 그대로 유지한다.

[질감·음향] 절제된 색, 젖은 면과 피부의 실제적인 재질, 미세한 필름 그레인. 눈과 얼굴이 읽히는 심도. 빗방울이 콘크리트와 금속 차양에 닿는 소리, 걸을 때만 젖은 신발 밑창 소리, 면 옷감 마찰, 14–21초의 한 번 내쉬는 숨만 들린다. NO BGM: score, soundtrack music, instrumental, underscore, ambient musical pad, musical drone, tone bed, swell, sting, humming, singing, whistling, lyrics 없음. 대사 없음. 전 구간 NO BGM.

[마지막 프레임] 여성은 문 앞에 멈춰 골목 입구 쪽을 바라본다. 오른손은 몸 옆에 내려져 있고 머리카락 끝에 물방울이 맺혀 있다. 카메라는 눈에 초점을 둔 정면 3/4 미디엄 클로즈업으로 정지해 있다. 오른쪽의 따뜻한 역광과 비 소리가 이어진다.
```

원테이크의 주 경로는 후진 동행 → 정지 → 같은 축 전진 → 정지다. 감정 변화 때문에 접근하고 여운을 위해 멈춘다. 새 프롬프트를 반환할 때는 예시의 문자 수를 재사용하지 말고 최종 코드 블록을 측정한다.
