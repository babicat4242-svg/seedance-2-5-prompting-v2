# 모델 적용과 제작

## 범용 프롬프트가 기본

도구 미지정, 오프라인, 계정 없음, 프롬프트만 요청이면 자연어만으로 전체 장면을 완성한다. 이펙트 라이브러리의 원리로 작성할 수 있는 작업에 로그인·플러그인 설치·실시간 프리셋 조회를 요구하지 않는다.

효과의 원리와 생성기의 입력 사양을 분리한다. 원본 서비스의 업로드 슬롯·프리셋 ID·무료 크레딧·해상도·길이를 다른 도구의 요구사항으로 취급하지 않는다. 보조 프롬프트가 아닌 완전한 시각 과정이 필요하다.

## 모델이 지정된 경우

1. 이미 활성화된 해당 모델의 작성 스킬과 정확한 버전을 따른다. Seedance 2.5는 `seedance-2-5-prompting`이 길이·언어·태그·출력 형식을 결정한다. 이 스킬은 장면 안에 넣을 효과의 내용만 공급한다. 양쪽 문서를 반복해서 왕복 로드하지 않는다.
2. 다른 모델은 현재 공식 문서나 노출된 도구 스키마에서 필요한 기능만 확인한다. T2V/I2V, 다중 참조, 첫·끝 프레임, 영상 참조, 마스크, 시간 제어는 서로 다른 기능이다.
3. 확인된 기능에만 해당 문법과 값을 쓴다. 미확인 모델 버전이나 고유 토큰을 발명하지 않는다. 원본 서비스의 효과 이름은 설명용 별칭으로만 남기고 실제 프롬프트에는 동작을 풀어 쓴다.
4. 특정 기능을 확인하지 못했어도 일반 텍스트로 가능한 초안은 제공한다. 예를 들어 단일 이미지 입력만 확인됐다면 다른 이미지를 가짜 태그로 연결하지 않는다.
5. 변환 뒤에도 요청한 이야기·길이·효과 대상·컷 정책·음향·끝 상태가 유지되는지 확인한다. 원테이크를 자동으로 여러 생성 단계로 분할하지 않는다.

## 재현 수준과 대안

- **자연어로 의도 전달:** 상승, 분리, 용해, 정지 대비처럼 보이는 변화를 완전히 서술한다. 결과 일치 보장은 하지 않는다.
- **참조로 보강:** 사용자가 준 이미지/영상의 얼굴, 제품, 동작, 효과, 카메라 중 어떤 요소를 가져올지 역할을 지정한다. 없는 원본은 요구사항으로 만들지 않는다.
- **편집·합성:** 정확한 복제 수, 프레임 단위 타이밍, 완전한 루프, 기하학적 정렬이 요구되면 레이어·마스크·키프레임·후반 합성을 제작 대안으로 제시한다. 해당 앱의 실제 기능·작업 절차가 필요하면 그 앱의 현재 문서를 확인한다.

대안은 사용자가 요구한 재현 수준에 맞춘다. 단순 초안에 제작 도구 선택을 강요하지 않는다. 정밀성이 부족한 경우 단일 생성으로 보장한다고 하지 않는다.

## 실제 생성 요청

사용자가 정한 생성 도구를 사용한다. 연결된 도구가 여러 개라는 이유로 Higgsfield를 자동 선택하지 않는다. 생성 요청에서 도구가 미정이고 실행 비용·결과에 영향을 주면 필요한 선택을 확인하되 완성한 프롬프트를 먼저 준비한다.

실행 여부와 생성 완료 여부를 구분한다. 작업 ID가 이미 있으면 기존 작업을 확인하고 중복 제출하지 않는다. 접근할 수 없으면 완성된 프롬프트와 필요한 설정을 제공하며 영상까지 생성했다고 말하지 않는다.

## 완전한 범용 예시

사용자 요청: 인물 없는 향수 광고, 공중 정지, 프롬프트만. 아래는 특정 모델의 기능이나 실제 원본을 가정하지 않는 창작 예시다.

```text
어두운 스튜디오의 낮은 석재 받침 위에 투명한 향수병 하나가 정면을 향해 서 있다. 병이 수직으로 천천히 떠오르고, 주변의 작은 물방울도 서로 다른 높이에서 정지한다. 병과 물방울은 공중에서 위치를 유지한다. 카메라는 병 정면을 향한 짧은 직선 경로로 서서히 접근한다. 측후방의 부드러운 빛이 유리의 두께와 액체의 가장자리를 드러낸다. 병의 형태와 뚜껑, 라벨은 유지되고 정면은 카메라를 향한다. 마지막에는 카메라가 멈추며 공중에 떠 있는 병과 그 아래 떨어진 그림자를 읽을 수 있는 구도로 머문다. 하나의 연속된 숏이며 화면에는 병과 받침, 물방울만 등장한다.
```
