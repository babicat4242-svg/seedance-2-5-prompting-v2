# 영상 효과 연출 · 분석 기반 완성형 프롬프트 모음

원본 예시 **213개**(아이캔디 A–J 132개 + 기존 힉스필드 포함 목록 81개)를 확인했다. 움직이는 원본 212개는 시간순 표본 프레임을 직접 확인했고, Dreamcore 1개는 정지 원본만 확인했다. **뮤직비디오 213개·브랜드필름 213개, 총 426개**의 완성형 창작 프롬프트가 있다.

213은 서로 다른 출처 카드 수다. 같은 원리가 두 라이브러리에 나타날 수 있으므로 고유 효과 종류 수로 해석하지 않는다. 힉스필드에서 사용자 요청으로 제외했던 그림·명화 실사화 6개는 제외를 유지했다.

## 읽는 방법

원본 미디어 → 시간순 프레임 이미지 → 실제 관찰과 한계 → 연출 원리 → 장면에 맞춘 완성 프롬프트 순서로 읽는다. 전체 프레임의 연속 재생·음향 분석·실제 영상 생성 테스트를 했다는 뜻은 아니다. 원본 이름만으로 AE 프리셋 설치나 단일 생성 재현을 보장하지 않는다.

원본 미디어는 각 카드에 직접 삽입했다. 미디어를 지원하는 뷰어에서는 GIF/WebP/MP4로 볼 수 있고, 지원하지 않는 뷰어에서도 로컬 프레임 모음과 프롬프트 본문을 읽을 수 있다. 프레임 모음은 분석용 추출 이미지이며 브라우저 화면 캡처가 아니다.

## 용도별 찾기

- [뮤직비디오용 색인](music-video-index.md): 퍼포먼스·시각 반복·감정 변화에 맞춘 프롬프트.
- [브랜드필름용 색인](brand-film-index.md): 제품 형태·재질·브랜드 감각에 맞춘 프롬프트.
- 영화 장면은 [장르별 연출 기준](../genre-direction.md)의 인물·갈등·인식 변화 기준으로 같은 원리를 다시 설계한다. 이 모음의 426개는 뮤직비디오와 브랜드필름 예시이며 영화용 별도 213개를 작성했다는 뜻은 아니다.

## 확인 시 특히 구별할 항목

- [Transitions](eyecandy/transition.md): 사용자가 보여준 입술 GIF. 금속 치아 확대 뒤 밝은 인물 장면으로 연결된다.
- [Masking](eyecandy/masking.md): 다른 원본이다. 사용자 입술 GIF와 혼동하지 않는다.
- [Eyes in](higgsfield/eyes-in.md): 회전하며 눈에 접근하는 원본 관찰과, 암부에서 수평을 되찾아 목적지로 연결하는 창작안을 구분한다.
- [Lidar transition](higgsfield/lidar-transition.md): 목록 설명의 기울기와 실제 영상의 스캔→실사 변화를 구분한다.
