# 효과와 카메라를 함께 연출하기

좋은 효과 장면은 관객의 시선을 어디에 붙잡고, 언제 기대를 만들고, 어떤 변화로 보상하며, 끝에 무엇을 남길지 설계한다. 효과 이름을 한 문장 추가하는 것으로 완성하지 않는다. 화려함의 양을 품질로 취급하지 않는다.

## 장면의 안무
1. 목적: 사건·감정·브랜드 감각·제품 정보 중 이번 장면이 남길 것을 정한다.
2. 시선: 시작에 읽힐 대상과 효과의 중심을 정한다. 예를 들어 Eyes in은 얼굴에서 특정 눈으로 시선을 모은다.
3. 기대와 발동: 시선 이동·손짓·광원의 스침·음악 변화처럼 장면 안의 계기에서 효과를 시작한다. 계기가 필요 없는 추상 장면에는 억지 행동을 추가하지 않는다.
4. 전개: 주체 동작, 카메라 본체 이동, 화면 롤, 초점, 효과, 편집, 음향을 각각 정의하고 시점을 맞춘다. 목적이 다른 복합 동작은 허용한다. ‘주 이동 하나’를 이유로 사용자가 요청한 회전+접근을 삭제하지 않는다.
5. 리듬: 읽히는 시작, 가속 또는 변화, 절정, 감속 또는 여운을 장면에 필요한 만큼 쓴다. 일정 속도·정지·급정지도 의도에 맞으면 유효하다. 모든 숏에 같은 속도 곡선을 적용하지 않는다.
6. 도착: 카메라의 위치·방향·속도·초점과 주체 상태를 정한다. 다음 장면이 있으면 연결점을 맞추고, 단독 장면이면 감정 또는 제품이 읽히는 끝 구도를 남긴다.

아이디어 요청은 서로 다른 연출 논리를 비교한다. 예컨대 친밀한 감정은 작은 움직임과 긴 관찰, 후렴 진입은 선명한 가속과 공간 공개, 브랜드 디테일은 재질을 읽는 접근과 절제된 복귀를 후보로 삼는다. 장르만 보고 자동 선택하지 않는다. 최종안에서는 이 장면에 맞는 이유를 짧게 설명하고 완전한 프롬프트를 제공한다.

## Eyes in · 사용자 선호의 구체적 적용

사용자는 단순한 직선 눈 줌보다 **화면이 회전하면서 한쪽 눈으로 들어가는 연출**을 좋은 예로 들었다. Eyes in 아이디어를 제안할 때 이 조합을 우선 검토한다. 모든 효과의 공통 의무나 모든 눈 장면의 고정 처방으로 확대하지 않는다. 사용자 지정 고정 카메라·무회전·속도·컷 정책은 우선한다.

- 회전은 카메라 광축 주위의 **롤**로 정의한다. 얼굴 주변을 도는 오빗, 인물의 머리 회전과 구별한다.
- 먼저 선택한 눈을 시선의 중심에 놓고 그 중심으로 물리적으로 접근한다. 롤과 접근을 별도 절로 쓰되 같은 구간에서 결합한다. 이동 중 눈이 프레임 가장자리로 밀리지 않게 목표점을 유지한다.
- 얼굴에서 홍채로 접근할 때 회전 속도를 올릴 수 있다. 홍채 디테일을 읽을 구간과 동공이 화면을 채울 순간을 확보한다. 눈 자체를 비틀거나 얼굴 형태를 변형시키는 것으로 대체하지 않는다.
- 목적지의 원형·빛·방향 등 실제 장면의 연결 요소를 정한다. 다음 장면에서도 같은 회전을 잠깐 이어 감속하거나, 명시한 컷에서 안정된 대비를 만든다. 매번 눈 안에 우주·터널을 넣지 않는다.
- 회전 방향·양·시작 속도·가속·끝 자세는 현재 장면에 맞춘다. 특정 각도나 완벽한 재현을 보장하지 않는다. 목적지가 정해지지 않았으면 새 제안임을 명시한다.
- 불편한 안구 찌그러짐·치아 같은 다른 부위 출현·얼굴 교체는 의도된 전환과 구별해 막는다. 인물 정체성과 눈의 정상적 형태를 유지한다.
- 실제 무편집 요청에는 연속된 환상 경로를 설계하고, 동공 암부를 이용한 컷은 컷이 허용될 때 명시한다. 원본 음원·NO BGM·무음 계약을 유지한다.

### 완전한 창작 예시 · Eyes in
장면 가정: 6초 패션필름, 밤의 얼굴 클로즈업에서 원형 천창 아래 모델로 연결. 참조 파일 없음. 이 설정과 회전은 사용자 선호를 응용한 창작이며 원본 영상 분석 결과가 아니다.

```text
씨댄스 2.5, 텍스트 기반 6초 패션필름, 16:9. 검은 재킷을 입은 성인 모델의 얼굴 클로즈업에서 시작해 밝은 원형 천창 아래 같은 모델의 전신으로 연결한다.
0–1.5초: 모델이 렌즈 가까이 시선을 옮긴다. 카메라가 짧게 접근해 모델의 왼쪽 눈을 프레임 중심에 놓는다. 얼굴과 머리는 회전하지 않는다.
1.5–3.5초: 카메라는 중심에 둔 눈을 향해 계속 전진하면서 광축을 중심으로 시계 방향으로 롤한다. 접근과 롤은 함께 가속하지만 눈의 위치는 중심에 유지된다. 정상적인 홍채가 점차 커지고 동공이 화면 전체를 채운다.
3.5초: 동공의 원형 암부에서 다음 장면의 원형 천창으로 한 번 매치컷한다. 물리적으로 안구를 뚫는 장면은 없다.
3.5–5초: 천창을 향하던 카메라가 같은 방향의 롤을 짧게 이어가며 아래로 틸트해 그 아래 선 모델을 드러낸다. 롤은 감속하고 마지막에는 수평 구도로 안정된다.
5–6초: 같은 모델이 카메라를 바라보는 전신 구도를 유지한다. 검은 재킷과 얼굴 정체성을 이어가고 밝은 공간에서 의상 실루엣을 읽게 한다. 배경음악과 대사 없이 옷감 마찰과 공간의 잔향만 사용한다. 생성 자막과 로고는 없다.
```

## 제출 전 장면 검토
- 이 변화가 장면의 목적에 기여하는가?
- 기대·발동·절정이 읽히며 필요한 디테일을 놓치지 않는가?
- 카메라·인물·효과의 움직임이 서로 구별되는가?
- 복합 동작이 목적을 공유하면서 경로·초점·타이밍에서 양립하는가?
- 끝에서 감정·제품·공간이 읽히고 다음 상태에 연결되는가?
한 요소가 약하면 해당 층의 동기·타이밍·끝 상태를 고친다. 효과를 더 붙이는 것으로 해결하지 않는다.
