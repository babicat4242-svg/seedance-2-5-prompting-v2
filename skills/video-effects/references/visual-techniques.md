# 영상 효과 연출 · 기법 자료

뮤직비디오·브랜드필름·영화에 넣을 카메라·구도·조명·합성·편집·질감 효과를 선택할 때 사용한다. 사용자에게는 공통 이름인 **영상 효과 연출**로 안내한다. Eyecandy와 Higgsfield는 출처 구분이다.

## 자료 선택
- 실제 예시의 움직임·프레임·완성 프롬프트는 [213개 분석 색인](prompt-library/index.md)을 먼저 읽는다. 아래 분류 체계와 개념 카드보다 구체적인 원본 동작의 근거로 우선한다.
- 카메라·구도·공간·전환: [기법 색인](../../eyecandy-visual-development/references/taxonomy.md)과 [장면 의도별 후보](../../eyecandy-visual-development/references/intent-routing.md)를 보고, 필요한 [상세 기법](../../eyecandy-visual-development/SKILL.md)만 읽는다. 기존 디렉터리는 호환성을 위한 자료 저장소다.
- 변형·분신·시간·그래픽 스타일: [효과 카드](effect-selection.md)를 읽는다.
- 자료별 항목 수에는 중복과 스타일 분류가 있으므로 합산해 고유 효과 수나 분석 완료 수로 보고하지 않는다.

## 움직이는 예시의 확인
GIF·애니메이션 WebP·영상은 시간축이 있는 자료다. PNG 캡처나 첫 프레임만으로 변화와 효과를 확정하지 않는다. 제공된 페이지에 원본이 있으면 그 원본을 먼저 확인하고 사용자에게 재첨부를 요구하지 않는다.
관련 미디어를 재생하거나 여러 시점을 추출해 시작·발동·변화·종료·반복 경계를 확인한다. 재생 확인, 시점 프레임 확인, 공개 설명만 확인, 정지 이미지 확인을 구분한다. 소리를 듣지 않았다면 음향을 확인했다고 하지 않는다. 접근 실패 시 설명 기반 초안으로 표시하며 분석 완료 사례에 포함하지 않는다.

## 효과별 기록
이름과 출처 / 확인 방식 / 실제 관찰한 변화 / 주체·카메라·조명·VFX·편집의 역할 / 시작→과정→끝 / 반복·연결 / 뮤직비디오 적용 / 브랜드필름 적용 / 보존할 대상 / 새로 작성한 복사용 효과 문장.
관찰한 사실과 창작 적용안을 분리한다. 브랜드필름에서는 제품 형태·재질·로고가 읽혀야 할 시점을, 뮤직비디오에서는 확인한 음악·퍼포먼스의 변화점을 기준으로 적용한다. 명칭만으로 After Effects 프리셋이나 단일 생성 재현이 가능하다고 말하지 않는다.

## 모든 기법·효과의 장면별 각색

이 원칙은 전환뿐 아니라 촬영·구도·조명·광학·시간·질감·그래픽·합성·복제·변형·공간 연출에 공통 적용한다. 아이캔디와 힉스필드는 출처이며 원본 소재를 복사하는 고정 처방이 아니다.

사용자가 동일 재현을 요청하면 그 요청을 따른다. 그 밖의 적용·아이디어 요청에서는:
1. 현재 장면의 행동·감정·제품 정보·브랜드 톤·퍼포먼스 목적을 먼저 읽는다.
2. 해당 예시의 실제 작동 원리를 추출한다. 변하는 대상, 유지되는 대상, 시작·변화·끝, 카메라와 효과의 관계를 구분한다. 움직임을 확인하지 못했다면 설명 기반 제안이라고 표시한다.
3. 작동 원리를 장면의 대상·공간·시간·재질에 맞게 다시 설계한다. 원본의 인물·제품·장소·의상·길이·음악을 자동 상속하지 않는다. 반드시 다음 장면이나 전환을 만들 필요는 없다.
4. 아이디어 요청에는 목적에 맞는 서로 다른 안을 제시한다. 원본의 특정 특징 하나만 반복하거나 모든 효과를 확대·포털·매치컷으로 바꾸지 않는다.
5. 선택한 안을 완전한 프롬프트로 작성한다. 요청된 참조·길이·컷·음향·보존 조건을 유지하고 원본 관찰과 창작 적용을 구분한다.

분야별 설계 초점:
- 카메라·구도: 이동으로 무엇이 드러나는지, 정지로 무엇이 읽히는지.
- 조명·광학: 어느 부위·재질을 언제 드러내고 감추는지.
- 질감·그래픽: 어디에 적용하고 어떤 디테일을 계속 읽게 할지.
- 복제·합성: 무엇을 몇 개로 나누고 어떤 관계·깊이·시간차를 줄지.
- 시간 변화: 멈추거나 빨라지는 대상과 계속 움직이는 대상이 누구인지.
- 물성·공간 변형: 어느 경계가 어떤 계기로 바뀌며 무엇으로 끝나는지.
- 전환: 앞뒤 장면의 연결 요소와 넘겨주는 시점.

완성형 프롬프트 모음도 이 공통 원칙을 따른다. 각색 예시를 제공하되 실제 작업에서는 장면에 맞춰 다시 작성한다. 공통 지침을 추가했다는 사실을 전체 미디어 분석 완료로 보고하지 않는다.

## 장면에 맞는 전환 아이디어

원본은 시각적 원리를 배우는 참고다. 사용자가 동일 재현을 명시한 경우에는 충실히 재현하고, 보통의 적용 요청에서는 원본 소재·장소·동작을 자동으로 가져오지 않는다. 완성형 예시는 고정 처방이 아닌 적용 예시다.

1. 현재 장면의 마지막 행동·구도와 다음 장면의 첫 행동·구도를 읽는다. 양쪽 장면이 없으면 현재 브리프에 맞는 다음 장면을 제안했다고 명시하며 기존 설정처럼 말하지 않는다.
2. 전환 목적을 정한다: 제품의 재질을 공간으로 확장, 퍼포먼스의 에너지를 다음 장면으로 전달, 감정 변화, 시간·장소 이동 등. 장면에 필요 없는 장식 전환을 추가하지 않는다.
3. 양쪽에 이미 존재하거나 자연스럽게 등장할 연결점을 찾는다: 형태·반사·질감·색·빛·동작 방향·가림·구도. 효과 이름을 먼저 정하고 연결용 소품을 억지로 넣지 않는다.
4. 원본에서 관찰한 원리를 현재 연결점으로 재설계한다. 예컨대 디테일 확대 전환은 금속 치아가 아니라 현재 장면의 물방울·제품 표면·눈의 반사·천의 결 등 적합한 대상을 쓸 수 있다. 모든 후보를 확대나 포털로 만들지 않고 매치컷·가림·동작 연결도 비교한다.
5. 아이디어 요청에는 서로 다른 원리의 2–3개 후보를 제시하고 장면에 맞는 이유를 짧게 설명한다. 프롬프트만 요청하면 가장 적합한 안을 골라 완전한 프롬프트로 작성한다. 사용자 선택이 이미 있으면 다른 안을 강요하지 않는다.
6. 선택한 안은 `나가는 장면 → 연결 요소의 변화 → 전환 시점 → 들어오는 장면 → 연속성`으로 완성한다. 주체·카메라·합성·편집·음향을 구분하고 제품 가독성·인물 정체성·요청 길이·컷 정책을 유지한다.

브랜드필름 예: 향수병 위 물방울의 곡면이 화면을 채운 뒤, 같은 빛과 곡률의 새벽 호수로 연결한다. 향의 이미지와 장소가 브리프에 맞을 때 사용하는 창작 제안이다.
뮤직비디오 예: 보컬이 얼굴 앞으로 손을 스치는 동작을 가림으로 사용해, 같은 방향으로 팔을 뻗는 다음 장소의 안무로 잇는다. 이 역시 원본 GIF의 동작으로 주장하지 않는다.

## 씨댄스 적용
씨댄스 2.5는 [기본 작성 스킬](../../seedance-2-5-prompting/SKILL.md)이 최종 문법·길이·참조·음향·수정·출력을 담당한다. 선택한 효과는 요청한 비트에 시작·과정·끝을 풀어 넣는다. 전체 기본 스킬을 이미 사용 중이면 다시 왕복하지 않는다. 상세 카메라 변환은 [기존 연결 자료](../../seedance-2-5-prompting/references/eyecandy-camera-direction.md)의 선택·컴파일 절을 사용한다.

## 원본 매칭과 이름
사용자가 지목한 카드의 slug·미디어와 실제 제시 프레임을 먼저 대조한다. 인접 카드나 비슷한 이름의 예시를 대신 분석하지 않는다. 등록 이름은 원본 기법명을 유지하고 관찰한 움직임은 설명란에 쓴다. 새 각색의 특징을 별도 원본 효과명으로 만들지 않는다.
