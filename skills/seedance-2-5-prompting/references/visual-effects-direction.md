# 범용 시각 효과를 Seedance 2.5 장면에 통합하기

영화·광고·브랜드필름·뮤직비디오의 시각 효과를 설계하거나 Higgsfield에서 본 장면의 원리를 옮길 때 사용한다. 효과는 장면 목적에 따라 선택한다. 모든 영화·광고·뮤직비디오에 VFX를 의무적으로 추가하지 않는다.

## 자료와 역할

공통 진입점은 ‘영상 효과 연출’이다. 아이캔디 카메라·구도·조명·전환과 움직이는 예시도 [공통 기법 자료](../../video-effects/references/visual-techniques.md)에서 선택한다. 기존 81개는 힉스필드 기반 효과 카드의 수이며 이 전체 라이브러리의 고유 효과 수나 영상 분석 완료 수가 아니다.

- [범용 video-effects](../../video-effects/SKILL.md): 특정 서비스 없이 효과를 완전한 시각 과정으로 풀어 쓰는 기준.
- [효과 라이브러리](../../video-effects/references/effect-selection.md): 시간 정지·레이어 분리·분신·소멸·공간 변형 등에서 현재 장면과 관련된 항목만 선택.
- [영화·광고·뮤직비디오 적용](../../video-effects/references/genre-direction.md): 같은 효과를 서사·제품 정보·음악과 퍼포먼스에 맞춰 각색.

`seedance-2-5-prompting`이 버전, 요청 길이, 실제 태그, 언어, 문자 수, 수정 처리, 출력 순서를 결정한다. `video-effects`는 효과의 내용만 제공한다. 이미 기본 스킬을 사용 중이면 범용 가이드의 모델 라우팅으로 다시 돌아가지 않는다. 이 연결은 힉스필드 계정·MCP·프리셋을 요구하지 않는다.

효과 색인의 81개 중 관련 카드만 선택한다. 그림·명화를 실제 인물로 재현하는 유형은 추천에서 제외한다. 잉크·종이·색감은 화면 스타일로 유지하되 확인되지 않은 시간 변화는 새 각색으로 구분한다.

- Monster dab: 사람 참조 1장과 몬스터 참조 1장을 분리한다. 실제 태그 내용으로 사람의 얼굴·의상과 몬스터 외형·재질을 바인딩한다. 전경 사람 뒤 하늘에서 몬스터가 낙하·착지하고 조명·원근·그림자로 공간을 통합한다.
- Scrapbook collage: 인물 참조에 배경·원하는 소품의 이미지 또는 설명을 추가할 수 있다. 사용자 소품은 기존 사진의 해당 소품보다 우선하고, 배치·크기·접촉을 정해 중앙과 인셋의 형태·색·재질을 연결한다. 실제 인물·배경·소품 태그를 역할별로 보존한다. 중앙 전신은 지정 배경에 놓고 인셋은 같은 인물의 디테일을 동시에 보여준다. 인셋 배경은 지정 우선, 미지정이면 동일 배경의 흐린 크롭을 사용하며 단순화도 선택 가능하다.
- 두 구성 모두 실제 업로드 태그를 재번호화하지 않는다. 이미지가 없으면 보았다고 주장하거나 태그를 발명하지 않는다. 생성 UI의 복수 참조 지원은 제작 단계에서 확인한다. 원본 프리셋의 한 이미지 제한을 작성 규칙으로 가져오지 않는다.

## 모든 효과의 창작 적용

촬영·조명·질감·시간·복제·합성·물성·공간 변형·전환에 [공통 각색 원칙](../../video-effects/references/visual-techniques.md)을 적용한다. 실제 관찰한 작동 원리를 장면 목적과 브랜드·퍼포먼스에 맞게 바꾸며 원본의 인물·장소·동작을 자동 복사하지 않는다. 동일 재현 요청은 그 지시를 우선한다.

## 장면 선택 단계에 적용

1. 현재 활성 브리프에서 끝의 감정·전달할 정보·퍼포먼스의 역할을 파악한다.
2. 효과가 요청됐거나 장면의 명시된 초현실적 사건을 표현할 때 해당 원리를 선택한다. 사용자가 효과를 정했다면 핵심을 유지하고, 그 효과의 등장인물·상품·장르를 원본 예시에서 자동 상속하지 않는다.
3. `시작 상태 → 발동 계기 → 변형 대상과 과정 → 도달 상태 → 다음 비트 연결`을 기존 타임라인의 관련 비트에 넣는다. 효과 때문에 요청한 길이를 바꾸거나 고정된 3초/5초 구간을 추가하지 않는다.
4. 주체 동작, 효과, 카메라, 편집, 음향을 분리한다. 카메라는 기존 CAMERA 규칙의 렌즈·고정/주이동·경로·끝 구도로 작성한다. 배경이 회전하는데 카메라가 자동으로 회전한다고 해석하지 않는다.
5. 유지 영역과 변화 영역을 나눈다. 얼굴·제품 보존 문장이 사용자가 요청한 용해·복제·공간 접힘을 금지하지 않게 한다. 제품 원형은 변형 전후 지정한 비트에서 읽히게 할 수 있다.
6. 완전한 프롬프트 안에 동작을 풀어 넣는다. “Cutout 프리셋”, “Bullet time 적용” 같은 이름만으로 끝내거나 관련 없는 서비스 슬롯을 추가하지 않는다.

## 제작 유형별 선택

- **영화:** 발동 계기, 누구의 지각인지, 인물의 반응, 사건 뒤 결과를 연결한다. 조용한 드라마 장면에도 미세한 공간 변화나 국소 정지가 가능하지만 요청한 사실적 톤을 존중한다.
- **광고:** 어느 순간 제품 형태·라벨·재질·기능이 보이는지 정하고 그 주변으로 효과를 배치한다. 인물 없는 공중 부유 제품에는 Character 원본을 요구하지 않는다.
- **뮤직비디오:** 효과의 등장·반복·복귀를 실제 확인한 음원 또는 요청된 곡 구조에 연결한다. 분신·시간 정지가 가창·안무·립싱크를 덮어쓰지 않게 한다. 듣지 않은 BPM이나 박자 시각을 만들지 않는다.

## 연속성·음향·참조

- 사용자가 원테이크를 지정하면 변형 과정과 카메라 경로를 연속시킨다. 레이어 전환·암부·구름을 숨은 컷으로 바꾸지 않는다. 편집 대안이 필요하면 대안임을 설명하고 사용자 컷 정책을 유지한다.
- 효과가 영상에 보이는 시간의 흐름을 바꿔도 원본 음원, NO BGM, 무음 등 음향 계약은 별도로 유지한다.
- 실제 `@Image7`, `@Audio2` 등의 태그를 그대로 보존한다. 효과 참고 영상은 지정된 동작·VFX만 전달하고 원치 않는 얼굴·의상·음원을 상속하지 않는다.
- 효과 도중의 의도된 변형과 결과의 비의도적 오류를 구별한다. 실패 수정은 해당 원인만 보강해 전체 활성 프롬프트를 다시 작성한다.

## 반환 전 점검

효과 이름을 삭제해도 시작·과정·끝의 화면을 그릴 수 있는가? 감정·제품 정보·퍼포먼스에 필요한가? 대상 동작과 카메라가 충돌하지 않는가? 마지막 상태가 다음 비트와 이어지는가?

범용 가이드의 출력 예시 대신 기본 스킬의 완전한 프롬프트·정확한 문자 수·참조 역할·카메라 근거 형식을 유지한다. 모델 사양을 바꾼다고 주장하지 않는다. 실제 생성 요청이 없으면 프롬프트 작성만 수행한다.
