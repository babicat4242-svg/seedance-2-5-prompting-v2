# 요청 길이에 맞춘 뮤직비디오 연출

뮤직비디오는 기본 `seedance-2-5-prompting` 안에서 작성한다. 10초·15초·20초·30초는 길이 설정이며 별도의 작성 스킬이나 고정 생성 단위가 아니다. 공연·춤·연주·음악 기반 서사에 필요한 연출만 이 참고자료에서 더한다.

## 길이와 출력

- 요청한 시작부터 종료 시각까지 하나의 타임라인을 구성한다. 짧으면 비트 수와 여운을 줄이고, 긴 장면은 행동과 음악의 변화를 더 읽히게 배치한다. 고정된 4–6비트나 30초 도입·절정 구조를 강제하지 않는다.
- 사용자 요청 없이 10초 단위 분할, 잔여 시간 늘리기, 슬로모션으로 분량 채우기를 하지 않는다. 길이를 바꾸는 수정은 같은 구성의 시간을 다시 설계한 전체 교체 프롬프트로 반환한다. 15초라는 이유로 Fast를 선택하지 않는다.
- 명시적으로 분할을 요청한 경우에만 구간을 나누고 전체 길이와 실제 음원 구간을 보존한다. 현재 UI의 생성 길이 제한이 확인되면 제한을 알리고 원하는 최종 길이와 맞는 분할 방법을 정한다. 확인하지 않은 Unlimited 제한을 가정하지 않는다.
- 언어·5,000자 상한·정확한 문자 수·복사용 전체 프롬프트·짧은 카메라 설명은 기본 스킬을 따른다. 영어를 자동 기본값으로 삼거나 캐릭터시트를 필수로 요구하지 않는다.

## 인물·의상·공간·태그

- 실제 제공된 인물, 의상, 공간, 안무, 카메라, 음원 참조의 역할을 나눈다. 같은 인물의 여러 의상은 별도 인물로 해석하지 않는다. 얼굴과 체형의 근거를 보존하고 배경 참조에서 새 얼굴을 상속하지 않는다.
- `@Image7`, `@Audio2`처럼 주어진 태그를 그대로 쓴다. 이미지를 네 장으로 제한하거나 `@Image1`–`@Image4`, `@Audio1`로 임의 재번호화하지 않는다. 실제 UI에서 새 태그가 배정됐을 때만 확인된 대응 관계를 반영한다.
- 캐릭터시트가 제공됐다면 지정된 인물·의상만 참고하고 시트의 칸·텍스트·스튜디오 배경을 재현하지 않는다. 일반 이미지 한 장을 캐릭터시트라고 부르거나 없는 자료를 가정하지 않는다.
- 의상 변경은 지정된 시점과 실제 가능한 탈착·가림·움직임에 연결한다. 원샷 안에 숨은 컷을 추가하지 않는다. 요청한 의상 변화와 변경 금지 조건이 양립하지 않으면 충돌을 짚는다.

## 퍼포먼스와 카메라

가창·안무·연주·정적인 포즈 중 요청된 퍼포먼스를 관찰 가능한 행동으로 쓴다. 카메라가 움직인다는 이유만으로 몸의 행동을 생략하거나, 정지한 퍼포먼스에 춤을 강제하지 않는다. 동작의 시작·힘·접촉·완료가 읽히는 시간을 준다.

댄서가 있으면 인원, 등장 순서, 화면 위치, 접촉·지지·착지 상태를 유지한다. 악기는 손·활·현·건반의 움직임과 음의 시작·끝을 연결한다. 새로운 댄서나 복장을 예시에서 자동 추가하지 않는다.

아이캔디는 음악과 장면의 감정·공간에 맞는 구도나 이동을 고르는 데 사용한다. 기본 카메라 규칙에 따라 고정 또는 하나의 주 경로를 두고 초점·끝 구도를 정한다. 요청된 고정 카메라, 원샷, 명시적 복합 이동을 보존한다.

## 음원과 전환

제공된 음원을 실제로 확인한 범위에서 구간, 발화, 쉼, 변화점에 맞춘다. 듣지 않은 음원의 BPM·타임코드·정확한 립싱크를 꾸며내지 않는다. 음원이 없으면 텍스트로 음악의 흐름을 제안할 수 있지만 첨부 태그나 소스 분석을 가정하지 않는다.

원본 음원 전용·음악 포함·NO-BGM·무반주 보컬·완전 무음은 [음향 규칙](no-bgm.md)을 따른다. 뮤직비디오라는 이름만으로 허용되지 않은 음악을 추가하거나 요청된 노래를 금지하지 않는다.

편집이 허용됐을 때만 컷과 전환 지점을 정한다. 매 컷에 플래시를 반복하는 공식을 쓰지 않고 장면 목적에 맞는 전환을 고른다. 여러 구간을 연결한다면 연속 연결은 자세·경로·구도·음원 시간을 맞추고, 독립 장면 연결은 허용된 하드컷을 명시한다. 마지막은 요청된 정지 구도나 움직임의 인계 상태로 마친다.
