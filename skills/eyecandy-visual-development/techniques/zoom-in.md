# Zoom

<!-- SOURCE-GROUNDED -->
## Technique Identity

- **EYECANDY category:** Zoom (registry slug zoom-in)
- **Source status:** taxonomy entry verified; sub-type anchors verified from homepage links.
- **Sub-types (verified):** Crash Zoom · Infinite Zoom
- **Visual purpose:** focal length changes against static camera position — sudden magnification isolates truth (Crash Zoom) or continuous magnification travels through nested worlds (Infinite Zoom).

<!-- DERIVED -->
## Use When

- Crash Zoom: comedic/punch reveals — snap to a face or detail exactly on a beat.
- Infinite Zoom: scale-perception journey — macro → object → room → city → cosmos in one move; ideal for product-origin stories and logo resolves.
- Escalation without physical camera travel (space-constrained sets, generation stability).
- Visual hook opening: crash-zoom into the cold-open subject.

## Avoid When

- Crash Zoom in serene luxury contexts (the snap is inherently aggressive) unless contrast is intended.
- Infinite Zoom with identity-critical faces at multiple scales — each nesting level re-renders and drifts.
- More than ~4 nesting levels in Infinite Zoom (coherence decays per level).
- Handheld realism scenes: optical zoom reads constructed.

## Required Inputs

Crash Zoom:
- Start framing (wide enough to make the snap meaningful), target subject/detail, trigger beat.
Infinite Zoom:
- Ordered level list (each level contains the next): e.g., droplet → bottle → iceberg → ocean.
- Alignment rule between levels (center-anchored or motif-shape-anchored).
- End-level target (usually product/logo/title card zone).

## Directing Rule

Crash Zoom:
- Snap duration 4–8 frames; arrive EXACTLY on the beat frame; zero settle wobble.
- Start frame must contain the target small but present — the audience should be able to verify where we land.
Infinite Zoom:
- Each level's center region IS the next level's full frame: design concentric alignment, not random crossfades.
- Constant apparent speed through all levels (accelerating feels like falling).
- Level boundaries may pass through doorways/apertures/macro surfaces for continuity logic.
- Final level decelerates and settles into composition.

## Storyboard Translation

Crash Zoom:
- **Setup frame:** wide baseline with target visible small.
- **Transition frame:** mid-snap motion-blurred radial frame (interstitial only).
- **Reveal frame:** tight landing composition, held ≥1s.
Infinite Zoom:
- One board frame PER LEVEL, plus boundary notes ("level 2's window becomes level 3's full frame").
- **Reveal frame** = final level key art.

## Image Generation Translation

Crash Zoom still = landing frame. Infinite Zoom stills = one image per level, each containing a legible center element that previews the next level; final image standalone-complete. Consistent palette across levels binds the journey.

## Video Generation Translation

Crash Zoom: "camera position locked; focal length snaps from [wide] to [tight] in ~6 frames arriving on [subject]; no shake." Infinite Zoom: "continuous forward magnification through nested levels L1→L4, each level's center becoming next level's full frame, constant rate, settle at L4." Declare every level's content explicitly; forbid crossfade-style transitions.

## Failure Modes

- Crash Zoom lands off-target or soft → reduce snap distance (start tighter); declare exact landing crop.
- Infinite Zoom level-drift: objects mutate across levels (identity decay) → fewer levels; strong shape anchors shared between levels.
- Crossfade leak (levels dissolve instead of magnifying) → forbid blend language; demand continuous magnification.
- Speed inconsistency (stuttering between levels) → constant-rate declaration + short total duration.

## Preservation Rules

Crash Zoom landing frame is an identity-critical still: face/product fully resolved. Infinite Zoom: product/logo appears ONLY at final level at full fidelity; intermediate levels show motif ancestors, not degraded brand marks. Wardrobe n/a mostly; spatial continuity defined by declared nesting logic. Motif link: Infinite Zoom literalizes verb-Scale-change ladder (object → architecture); Crash Zoom serves verb-Occlusion reveal of motif detail. Downgrade path: sequence of match-cuts between level framings when continuous zoom generation fails.
