# Set Transition

<!-- SOURCE-GROUNDED -->
## Technique Identity

- **EYECANDY category:** Set Transition
- **Source status:** taxonomy entry verified (category exists at slug); page definition not captured in this build — identity below is derived naming support.
- **Visual purpose:** the SET itself transforms in one continuous shot — walls rotate, furniture becomes other furniture, a room's geometry reconfigures — location change as a magic trick instead of a cut.

<!-- DERIVED -->
## Use When

- Spatial expansion with narrative meaning: the world literally rearranges around the subject (day→night, home→stage, city→interior).
- Brand film metaphor: product placement triggers environment transformation (kitchen becomes runway).
- Music video section change without an edit — one take credibility.
- Escalation: each transformation raises stakes visually.

## Avoid When

- Two or more full set transformations in one shot — audiences stop tracking geography.
- Subject identity must stay perfectly stable while everything moves (generation struggles; faces swim during world changes).
- The transformation has no logic link between states (random morph = noise). There must be a mechanical rhyme: door becomes window, table becomes ring.
- Time/budget realism in live-action contexts — flag that this is a VFX-heavy grammar when directing humans.

## Required Inputs

- World A and World B with a shared spatial skeleton (same camera-relative structure: doorway stays doorway, center stays center).
- Transformation trigger: subject action, object placement, lighting event, or camera arrival at a specific position.
- Morph order: which elements transform first → last.
- Anchor element for continuity (the one thing that does NOT change, usually the subject or hero object).

## Directing Rule

- Lock camera path FIRST (usually slow push or orbit segment), then design the transformation to complete exactly as the move ends.
- Transform periphery toward center: edges mutate first, anchor zone last.
- Mechanical rhyme required: every A-element maps to a B-element occupying the same screen region (lamp→streetlight, rug→pool of light).
- One lighting regime hands over to the other mid-transformation — this sells reality more than geometry does.
- Subject behavior bridges states: their action remains meaningful in both worlds (dancing in kitchen = dancing on stage).

## Storyboard Translation

- **Setup frame:** World A fully legible, trigger visible and motivated (hand reaches for switch / object set down).
- **Transition frame:** midpoint — half-morphed geometry, both lighting regimes visible, subject unchanged and centered.
- **Reveal frame:** World B complete, camera move settled, subject's ongoing action now recontextualized.

## Image Generation Translation

Stills can only show endpoints or the midpoint. Midpoint key art is the signature image: hybrid room where 2–3 elements are visibly mid-metamorphosis with clean mapping pairs, subject untouched at anchor position. Endpoint stills must each read as complete worlds.

## Video Generation Translation

One continuous shot. Declare: camera path and duration, anchor element (never transforms), ordered morph list with screen positions ("back wall panels rotate to become city windows left-to-right"), lighting handover moment (~50–70% duration), subject's continuous action. Forbid: cuts, subject relocation, anchor mutation.

## Failure Modes

- Global mush: everything warps simultaneously including the subject → enforce anchor + ordered peripheral morphing.
- Mapping breaks: lamp melts into abstract shape instead of becoming streetlight → name explicit pairs; limit simultaneous morph count to ≤4 regions.
- Camera drift during transformation (path wobbles) → shorten move; simpler paths survive generation better.
- Identity drift: face ages/changes across the morph → keep subject in stable lighting until after handover completes.

## Preservation Rules

Subject identity absolutely locked through the entire transformation — the world may lie, the person/product may not. Hero product: if present, it is either the anchor or the trigger, never collateral morph material. Logo integrity: brand surfaces exist in both worlds via mapped pairs if needed. Wardrobe persists. Motif link: the motif often IS the morph map (circular motif → round windows become round stage lights); coordinate with motif-system-link.md verb-Mutation. Downgrade path: split into two shots joined by match-cut on the mapped element pair.
