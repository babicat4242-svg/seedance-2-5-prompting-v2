## Fixed scene-intent vocabulary

`reveal · tension · escalation · elegance · impact · spatial-expansion · transition · visual-hook · climax · scale-perception · motif-linkage · isolation`

## Selection table

| Scene intent | Primary candidates | Supporting candidates | Notes |
|---|---|---|---|
| reveal | object-portal, pass-through, scale-shift | parallax | Reveal needs a hidden→shown order; pick the occluder or the scale trick before the subject |
| tension | dolly-zoom, locked-on, snorricam | silhouette | Tension = subject stable, world unstable (or reverse); never move everything at once |
| escalation | speed-ramp, zoom (Crash Zoom) | arc-movement | Escalation needs accelerating time or closing distance toward a beat |
| elegance | arc-movement (Y-Axis/X-Axis), central-framing | slow dolly via tracking grammar | Elegance = one smooth path, symmetric geometry, no cuts |
| impact | crash-transition, whip-pan, speed-ramp | flash-cut family (taxonomy-only) | Impact lands ON the cut; build approach + land cut on audio beat |
| spatial-expansion | parallax, pass-through, set-transition | scale-shift | Expand space by layering depth planes or punching through an occluder |
| transition | match-cut, match-motion, whip-pan, set-transition | crash-transition | Choose by what survives the cut: shape/position (match-cut), motion vector (match-motion/whip-pan), set logic (set-transition) |
| visual-hook | central-framing, silhouette, scale-shift (Big head/Giant/Miniature) | bullet-time (taxonomy-only) | First 3 frames must read as standalone key art |
| climax | scale-shift (Giant), arc spin, speed-ramp | locked-on | Climax = maximum contrast with the sequence's baseline scale/motion |
| scale-perception | scale-shift, dolly-zoom, parallax | tilt-shift (taxonomy-only) | One clear reference object must anchor the size read |
| motif-linkage | match-cut, match-motion | silhouette, reflections (taxonomy-only) | Motif enters/exits through the matched property; see motif-system-link.md |
| isolation | snorricam, locked-on, silhouette | shallow-focus (taxonomy-only) | Isolate by binding camera to subject or erasing environment |

## Selection procedure

1. Write the scene's purpose as one of the intents above. Two max.
2. Treat the row as a candidate list, not a ranking. Compare plausible candidates
   with plain coverage for the scene's action, emotional change, spatial geometry,
   available time, and user-specified camera/cut constraints. Read the relevant
   technique files and keep only candidates whose Required Inputs the brief/assets
   satisfy. Choose the best fit, not merely the first feasible effect; do not invent assets.
   If no taxonomy intent or technique fits, use ordinary film grammar without
   attributing it to EYECANDY.
3. Check Avoid When in the technique file against the current scene. Any hit → next candidate.
4. Check Preservation Rules against brand/face/product constraints. Any unresolvable
   conflict → next candidate or plain coverage.
5. Record: primary (1) + supporting (0–1). Justify both in one sentence each.

## Anti-forcing rules

- Neutral coverage beats forced technique. If the shot only documents action,
  direct it plainly.
- Do not reuse the same primary technique more than twice in any 6-shot run
  unless repetition is the declared device.
- Transition techniques serve scene connection; they are never the reason a
  sequence exists.
