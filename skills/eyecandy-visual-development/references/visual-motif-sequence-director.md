# Visual Motif Sequence Director — Detailed Reference

## Core philosophy

Do not create a storyboard as a random collection of beautiful shots or begin with conventional screenplay coverage. Build the sequence through:

`Visual Motif Map → Visual Rhyme → Match Cut Logic → Scale Transformation → Scene Invention → Storyboard Sequence`

Ask, “What visual element in the current image can transform into the next image?” Every scene should echo, transform, contrast, enlarge, miniaturize, repeat, distort, complete, or recall something elsewhere. The sequence should remain visually coherent with the sound muted.

Unless the user explicitly requests otherwise, do not depend on dialogue, lyrics, narration, or spoken-word transitions. Prioritize composition, silhouette, shape, scale, color, light, texture, objects, architecture, gesture, negative space, repeated geometry, spatial rhythm, visual rhyme, callbacks, and match-cut potential.

## Visual Motif Map

Before generating scenes, select 1–3 primary motifs and 1–3 secondary motifs. Motifs may be shapes, objects, colors, materials, gestures, costume silhouettes, or architectural geometry. A motif must mutate rather than merely repeat.

Example:

`black dot → pupil → pearl → overhead round table → circular headpiece → spiral staircase → moon → ceiling ornament → final overhead human formation`

Let motifs travel through `object → body → costume → environment → architecture → composition`.

Output the following map:

### A. Visual Thesis

One sentence describing the visual idea of the entire sequence.

### B. Primary Motif

Define the dominant recurring shape, object, color, material, or gesture.

### C. Motif Evolution

Show at least five transformations:

`Motif → Variation → Transformation → Scale Shift → Architectural Form → Final Callback`

### D. Secondary Motifs

List supporting motifs and their functions.

### E. Shape Language

Examples: circular/radial, vertical/monolithic, sharp/triangular, soft/organic, fragmented, symmetrical, elongated.

### F. Scale Language

Define deliberate fluctuation, such as:

`macro → portrait → full body → group → extreme wide → object insert → top shot → close-up`

### G. Environment Language

Define how the environment participates in the motif.

### H. Costume / Silhouette Language

Define how clothing and body silhouette echo the visual system.

### I. Object System

Choose recurring objects that can bridge scenes.

### J. Transition Grammar

Choose among shape, color, motion, graphic, scale, silhouette, light, object, spatial, and contrast matches.

### K. Final Callback

Specify which early visual motif returns in the final scene.

## Visual Rhyme Chain

Each scene inherits one visual property from the previous scene: shape, frame position, direction, color, gesture, silhouette, object, light source, texture, negative space, movement, or architectural form.

Example:

`centered pearl → moon in the same screen position → circular window → face framed by circular mirror → overhead circular staircase`

The physical location may change completely; the visual relationship must remain.

## Match-cut engine

- **Shape match:** a circle becomes another circle.
- **Position match:** an object occupies the same frame position after the cut.
- **Motion match:** a rotating skirt becomes a spinning fan or spiral staircase.
- **Gesture match:** a raised hand becomes a branch, sculpture, or architectural line.
- **Color match:** a red flower becomes a red room.
- **Light match:** a flame becomes sunlight or a glowing window.
- **Texture match:** skin becomes marble, fabric becomes cloud, or water becomes glass.
- **Scale match:** tiny jewelry becomes monumental architecture.
- **Silhouette match:** a body outline becomes a mountain, doorway, sculpture, or shadow.

Use enough match cuts to create visual intelligence, but do not force one into every scene.

## Scale transformation

Scale variation is mandatory. Use deliberate alternation among macro detail, extreme close-up, close-up, portrait, medium, full body, group tableau, wide, extreme wide, overhead/god shot, architectural shot, and object insert.

Whenever two or three consecutive scenes feel similar, break the pattern with a dramatic scale change. Let motifs grow through `jewelry → costume ornament → room decoration → architecture → landscape`.

## Graphic key art and tableau-first design

Each sequence should contain multiple frames that work as standalone key art. Useful graphic strategies include central or bilateral symmetry, radial composition, extreme negative space, a tiny human within monumental architecture, top-down geometry, strong silhouettes, frame-within-frame, doorway framing, corridor vanishing points, repeated formations, isolated objects, extreme close-ups, foreground obstruction, and surreal scale relationships.

Before camera movement, design the strongest still image. Determine:

1. subject
2. dominant shape
3. frame position
4. silhouette
5. foreground
6. background
7. negative space
8. light source
9. hero object
10. visual link to another scene

If the frozen frame would not work as a memorable full-page fashion editorial, redesign it.

## Environment and object systems

Locations are active participants. A corridor can repeat costume stripes; a staircase can repeat spiral jewelry; a circular window can echo the moon; a doorway can frame the subject; windows can resemble eyes; columns can mimic a human formation. Whenever possible escalate `small motif → human-scale motif → architectural motif`.

An important object should introduce or repeat a motif, bridge scenes, reveal character, transform scale, foreshadow, return as a callback, or create a match cut. Avoid decorative objects with no visual function.

## Contrast rhythm

Adjacent scenes should not have identical visual energy. Compose contrasts such as:

- wide ↔ close
- bright ↔ dark
- warm ↔ cold
- human ↔ object
- empty ↔ crowded
- horizontal ↔ vertical
- symmetry ↔ asymmetry
- soft ↔ hard
- organic ↔ architectural
- still ↔ kinetic
- realistic ↔ surreal

## Callback system

Recommended development:

- Early: introduce the motif.
- Early-middle: change its material.
- Middle: move it into costume or body.
- Late-middle: expand it into environment or architecture.
- Final: return it in its most powerful or unexpected form.

The final shot should visually complete something introduced earlier.

## Storyboard length modes

### 9 cuts

Best for a 10–20 second fashion film, key-art expansion, simple concept, or one strong transformation arc:

1. visual hook
2. motif introduction
3. first variation
4. scale change
5. hero tableau
6. motif transformation
7. spatial escalation
8. pre-climax callback
9. final iconic image

### 12 cuts

Best for a 20–40 second sequence, music-video section, richer visual development, or multiple environments:

1. hook
2. motif seed
3. portrait
4. object bridge
5. full-body tableau
6. architecture
7. detail interruption
8. surreal transformation
9. group or spatial escalation
10. callback
11. climax
12. final visual punctuation

### 15 cuts

Best for a 30–60 second music video, brand film, cinematic concept sequence, or multiple motif transformations:

1. graphic hook
2. motif seed
3. character introduction
4. object rhyme
5. silhouette transformation
6. environment reveal
7. detail insert
8. midpoint hero tableau
9. architectural expansion
10. visual interruption
11. motif mutation
12. scale escalation
13. major callback
14. climax
15. final iconic return

Do not follow these beats mechanically when a stronger visual rhythm exists.

## Scene invention engine

For each new scene:

1. Identify the strongest visual property in the previous scene.
2. Choose what survives: shape, color, motion, position, object, texture, silhouette, gesture, or scale.
3. Transform it.
4. Place it in a new context.
5. Change the shot scale or visual energy.
6. Create one iconic still.
7. Define how it connects to the next shot.

Never invent the next scene independently; the previous image visually seeds it.

## Storyboard output format

For each scene provide:

### SCENE 01 — SHORT VISUAL TITLE

**Frame**

Describe the strongest frozen image.

**Shot / Composition**

Specify shot scale, camera angle, symmetry, subject placement, and negative space.

**Visual Motif**

State which motif appears and how it changes.

**Environment / Hero Object**

Include only visually necessary elements.

**Action**

Give one simple, readable visual action.

**Light / Texture**

Explain only what materially affects the image.

**Visual Link → Next Scene**

Identify the element that transforms into the next scene.

**Transition Type**

Name the shape, motion, color, silhouette, scale, contrast, or other cut.

For an image-generation storyboard grid, additionally give:

`PANEL 01 — subject + composition + environment + dominant motif + light`

Keep panel descriptions visually precise and omit unnecessary plot explanation.

## Reference analysis

When given a film, video, storyboard, image set, or other reference, extract its visual grammar rather than copying its costume, palette, props, location, character, or art style. Analyze recurring motifs, shot-scale rhythm, graphic composition, shapes, object bridges, match-cut logic, architecture, silhouettes, callbacks, contrast rhythm, transitions, and motif evolution. Apply the grammar to the user's concept so the result is structurally inspired rather than visually copied.

## Anti-generic guidance

Avoid empty coverage such as a person merely walking down a hallway, looking into camera, turning, sitting, entering a room, or appearing in a random close-up or drone shot. If an action is necessary, give it a graphic function.

Instead of “a woman walks through a hallway,” use an image such as: “A tiny black silhouette crosses a perfectly symmetrical ivory corridor while circular doors decrease in size toward a single black point.”

## Quality control

Silently verify before presenting:

- A clear primary motif transforms rather than simply repeats and travels through multiple scales.
- Shot sizes vary, with memorable close-ups, wides, and unusual graphic angles when appropriate.
- Multiple scenes have key-art strength.
- Each scene inherits something from another while adjacent scenes remain differentiated.
- Match cuts are intentional.
- Architecture and objects participate in the visual system.
- An early motif returns and the final image completes the visual logic.
- The sequence remains coherent, rhythmic, and memorable with sound muted.

If any answer is no, redesign the weak scenes.
